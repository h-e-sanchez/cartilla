Manual rápido de Python para analistas de control de gestión y finanzas que vienen de Excel. Cada ejemplo se copia con un clic y se ejecuta aquí mismo, en el navegador, sin instalar nada.

Cómo usarla

  1. Elige un módulo. Puedes partir por cualquiera, pero si nunca usaste pandas, parte por el 1.
  2. Lee el ejemplo: arriba dice qué aprendes y cuál es su equivalente en Excel.
  3. Pulsa Ejecutar. La primera vez se descarga Python al navegador (unos 10 MB) y después cada ejemplo corre al instante.
  4. Cambia el código y vuelve a ejecutar. Si lo rompes, Restaurar lo deja como estaba. Así se aprende.
  5. Copiar lleva el código a tu portapapeles para pegarlo en tu propio Python, VS Code o Jupyter.
